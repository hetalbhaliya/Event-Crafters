# 🎉 Event-Crafters

A professional PHP and MySQL based Event Management System designed to simplify event planning, booking management, food services, user management, and event-related activities.

## 📌 Project Overview

Event-Crafters is a web-based Event Management System developed using PHP and MySQL. The system provides separate user and admin functionalities to manage events, bookings, food services, reviews, wishlist, and other event-related operations.

The main goal of this project is to provide a simple and organized platform for managing different aspects of event planning and booking.

## ✨ Key Features

### 👤 User Module
- User Registration and Login
- User Dashboard
- Browse Events
- Event Booking
- Booking Management
- Wishlist Management
- Food Services
- Coupon Validation
- Reviews and Ratings
- Receipt Generation
- User Profile Management

### 🛠️ Admin Module
- Admin Dashboard
- Event Management
- User Management
- Booking Management
- Food Management
- Gallery Management
- Review Management
- Coupon Management
- Order/Booking Status Management

## 💻 Technologies Used

- **Frontend:** HTML5, CSS3, Bootstrap
- **Backend:** PHP
- **Database:** MySQL
- **Server:** XAMPP / Apache
- **Tools:** Visual Studio Code, Git, GitHub
